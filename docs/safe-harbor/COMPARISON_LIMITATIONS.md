# What the frozen comparison measures

Experiment `experiment-a879d0fa4f5e499b89a43ed8b7f7f400` compares the implemented workflows, including their interaction with the common runtime. It does not isolate the model's reasoning ability or the causal effect of role splitting. No runtime, tool, prompt, criterion or scoring repair is applied during this experiment.

The independent critic identified a consequential limitation in the withheld-control scenario. The raw `table_slice` tool raises `PermissionError` when asked for an unavailable untargeted-control contrast. That non-transient exception ends the worker; its dependent tasks remain blocked. The higher-level `control_overlap` tool instead returns an explicit unavailable result under the same evidence revision. Both interfaces and that error policy are shared across arms, but the workflows reach them differently.

R0 runs its fixed checks with predefined arguments: its table slice uses the targeted comparison, and its control-overlap result reports missing controls. H0 and H1 choose arguments through model tool calls. Their initial packets explicitly report control unavailability, but the recorded inspection workers requested the unavailable untargeted table. This ended those cases before synthesis. H1's new reviewer could not intervene because it depended on the failed inventory task. The model chose the inventory request and the denied table request in the same response; it did not first receive an inventory result and then ignore it in a later response.

This is a real implementation failure, and the zero scores remain in the comparison. It is also a limitation of the runtime's error handling: a robust future implementation could return a bounded unavailable result to the model and permit reconciliation. That would require a new version and a separately frozen comparison. The current results cannot establish that this stopping behavior is intrinsic to agentic workflows, or that splitting roles alone caused it. R0's simpler fixed path is allowed to win; it is not weakened to produce a favorable adaptation result.

The exact matched failure traces, initial availability metadata, tool arguments, source versions and budgets are retained in the [withheld-control review](../../artifacts/safe_harbor/withheld-control-trace-review/README.md). The relevant implementation is [the shared tool boundary](../../backend/safe_harbor/runtime/worker.py), [the scientific table interface](../../backend/safe_harbor/science/tools.py), and [the fixed baseline specification](../../backend/safe_harbor/evaluation/baselines.py). No scores are recomputed or overridden by this disclosure.

Other limits remain: three loci from one publication, one locus per split, one stochastic run per assigned arm/case, independently computed but not human-reviewed answers, and incomplete biological evidence. A successful numerical answer does not establish biological safety. A saved structural change executing does not establish successful self-improvement. Proposal, evaluation and failed-attempt overhead must remain visible separately from any inference-cost comparison.
